# V12 Engine Simulator — ULTIMATE

Version finale du simulateur de moteur V12.

## Audio
Le moteur utilise de vrais enregistrements V12 issus du fichier fourni par l'utilisateur. L'enregistrement Lamborghini V12 original est découpé en plusieurs zones de régime puis mélangé en temps réel selon le régime moteur. Les zones sont jouées avec variation de vitesse/pitch, crossfade, filtre et volume selon l'accélérateur.

Source originale : “Lambo idle and rev.mp3” par cheesepuff, Freesound, CC0.

## Commandes
- START ENGINE : démarrage / arrêt
- − / + : rapports
- THROTTLE : accélérateur
- DECEL : frein moteur / décélération
- BRAKE : frein
- COMFORT / SPORT / SPORT+ : réponse moteur
- SOUND ON/OFF : audio
- Clavier : Espace = start, ←/→ = rapports, ↑/↓ = accélérateur

## Installation GitHub Pages
Publier tout le dossier tel quel. Ne pas déplacer le dossier `assets/audio`.
